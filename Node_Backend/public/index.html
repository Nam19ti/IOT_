🌍 ĐIỀU KHIỂN CỔNG TỪ XA QUA THINGSBOARD CLOUD

Hệ thống đã kết nối thành công tới ThingsBoard RPC.

Hướng dẫn cấu hình trên ThingsBoard:
1. Đăng nhập vào ThingsBoard Dashboard của bạn.
2. Thêm một Widget mới dạng Control widgets -> RPC Button.
3. Ở mục RPC method name, điền một trong 3 lệnh sau: OPEN (Tự đóng sau 3s), OPEN_MANUAL (Mở mãi mãi), hoặc CLOSE (Đóng gấp).
4. Nhấn nút trên ThingsBoard để điều khiển trực tiếp Trạm thu phí ở nhà!
